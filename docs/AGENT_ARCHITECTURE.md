# Архитектура агентов SKYNET 0.2

SKYNET 0.2 использует четыре уровня, которые можно запускать локально через
Ollama и переключать на облачные модели при наличии ключей.

## 1. Институт

`institute/router.py` принимает запрос и выбирает отдел. Сначала используется
быстрый реестр ключевых слов, затем классификация доступной облачной моделью,
а при отсутствии API применяется `DEFAULT_DEPARTMENT`. Отделы загружаются
лениво через `institute/registry.py`, поэтому запуск роутера не импортирует все
CrewAI-конвейеры сразу.

Каждый запуск получает `run_id`. Файл `runs/<run_id>.json` содержит отдел,
режим, время старта, статус и краткий результат или ошибку. История работает
без внешнего сервиса.

## 2. Отдел

Каждый отдел состоит из ролей, задач и локальной базы уроков:

`вход пользователя -> специализированные задачи -> проверка -> уроки`

Задачи выполняются в `Process.sequential`. Порядок задаётся `context` в
`config/tasks.yaml`, поэтому результат предыдущего этапа явно передаётся
следующему агенту. Менеджер не может случайно изменить порядок или породить
лишние делегирования во время локального запуска.

## 3. Агент

Все агенты получают единую политику из `institute/runtime.py`:

- `AGENT_MAX_ITER` ограничивает рассуждения;
- `AGENT_MAX_RETRY_LIMIT` ограничивает повторы;
- `AGENT_MAX_RPM` ограничивает частоту обращений;
- `AGENT_MAX_EXECUTION_TIME` ограничивает время одного агента;
- `respect_context_window=True` защищает длинные контексты.

Ограничения меняются через `.env`, без правки каждого отдела.

## 4. Контроль

Quality Control включён по умолчанию через `ENABLE_QUALITY_GATE=1`. Он получает
исходный запрос и результат отдела, затем проверяет требования, риски и
финальную формулировку. Для отдела Кодеров отдельный структурированный
вердикт ревью дополнительно блокирует Docker-деплой при `CHANGES_REQUESTED`.

`ENABLE_CREW_MEMORY=0` оставлен значением по умолчанию: CrewAI memory может
использовать embeddings и потребовать внешний провайдер. Локальная база
`knowledge/*_lessons.md` продолжает работать без API.

## Расширение

Чтобы добавить отдел, достаточно:

1. Создать пакет с классом CrewAI-конвейера.
2. Добавить его `DepartmentSpec` в `DEPARTMENT_REGISTRY`.
3. Добавить конфигурации агентов и задач.
4. Добавить тест маршрутизации и описать локальный fallback.

Роутер и история запусков подхватят отдел через единый реестр.
